요약
----
체크포인트 리서치가 공개한 분석에 따르면 북한 연계 해킹 그룹 라자루스는 윈도우 커널 제로데이 취약점(CVE-2026-68820)을 악용해 고도화된 `FudModule`(푸드모듈) 루트킷 v3.1을 유포했다. 공격 수법은 다음과 같다.

- 소셜 엔지니어링(채용담당자 사칭) 및 SEO 기반 사칭 웹사이트로 악성 뷰어 배포
- 정식 서명 소프트웨어를 악용한 DLL 사이들로딩(DLL sideloading)
- 트로이목마화된 PDF 뷰어를 통한 초기 침투
- Microsoft Graph API 및 OneDrive를 이용한 추가 모듈 다운로드/배포
- 커널 제로데이로 권한 상승 후 ETW/Smart App Control 등 탐지 기능 무력화
- 취약한 웹메일/CMS에 RelayShell을 설치해 C2 트래픽을 정상 트래픽으로 위장

핵심 시사점: 취약한(미패치) 시스템, 악성 서명/소프트웨어 남용, 검출 방해, 합법적 서비스(Microsoft Graph/OneDrive) 악용이 결합되어 장기간 은밀한 침투·유지·명령제어를 가능하게 함.

OWASP Top 10 관점의 취약점 매핑 및 분석
---------------------------------

아래는 OWASP Top 10(2021 기준)의 카테고리와 이번 사례에서 드러난 관련 취약 영역 및 이유, 권고사항이다.

- A06: Vulnerable and Outdated Components — 설명: 공격자는 윈도우 커널 제로데이(CVE-2026-68820)를 이용해 권한 상승 및 루트킷 설치를 수행했음. 미패치 시스템은 직접적인 침해 경로가 된다.
  - 권고: 신속한 패치 관리, 자산 인벤토리·취약점 스캐닝, 긴급 패치 정책 수립 및 권한 최소화.

- A08: Software and Data Integrity Failures — 설명: 정식 서명 소프트웨어 악용(DLL sideloading), 트로이화된 뷰어, 업데이트/배포 체인 악용(Microsoft Graph/OneDrive를 통한 배포)이 데이터 무결성·공급망 신뢰를 훼손.
  - 권고: 실행 가능한 바이너리 및 로드 라이브러리의 무결성 검증(코드 서명 검증 강화), 서드파티 서명 검증 절차, 애플리케이션 화이트리스트, 소프트웨어 공급망 모니터링.

- A05: Security Misconfiguration — 설명: 외부 서비스(OneDrive, Graph API) 권한·설정이 과다하거나 웹서버/CMS 보안 설정이 취약해 RelayShell 등 페이로드 설치·유지에 이용되었음.
  - 권고: 최소권한 원칙, 외부 API 권한 검토·제한, 웹앱·CMS 기본 설정 점검 및 불필요 서비스 비활성화.

- A09: Security Logging and Monitoring Failures — 설명: 공격자는 ETW 및 Smart App Control을 무력화해 탐지·로깅을 방해했고, C2 트래픽을 정상 트래픽으로 위장해 모니터링을 회피함.
  - 권고: 탐지 방어 무력화 시나리오 대비(안티-탬퍼 보호), 외부망 모니터링(이상징후 기반), EDR/통합 로그의 무결성 확보 및 원격 보관, 네트워크 이상행위 기반 탐지 강화.

- A04/A01 (보조): Insecure Design / Broken Access Control — 설명: 권한 상승 이후 내부 권한 제어·분리 실패가 있으면 추가적인 횡적 이동과 중요 자산 접근이 가능해짐.
  - 권고: 네트워크·호스트 분리, 최소권한 및 세분화된 권한 정책, 애플리케이션 수준의 액세스 제어 강화.

간단한 기술적 권고 요약
-----------------

- 긴급: CVE-2026-68820 등 관련 패치 적용
- EDR 및 원격 로깅 강화, ETW/Smart App Control 무력화 탐지 룰 추가
- 소프트웨어 공급망 및 서명 검증 프로세스 강화, DLL 사이들로딩 방지 규칙 적용
- 외부 API(OneDrive, Graph) 접근권한 최소화 및 애플리케이션 로그·네트워크 로그의 상시 모니터링
- 웹메일/CMS의 취약점 점검과 WAF/웹로그 상관분석으로 RelayShell 유입 경로 차단

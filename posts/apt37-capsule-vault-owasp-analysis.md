## 요약

2026-07-13 보안뉴스 보도에 따르면 지니언스는 북한 소행으로 추정되는 APT37의 신종 캠페인 ‘오퍼레이션 캡슐 볼트(Operation Capsule Vault)’를 공개했습니다. 공격자는 학술행사와 연구계의 정보 교류 관행을 악용해 표적형 스피어피싱을 수행했고, 상용 클라우드 링크를 이용해 이메일 보안 게이트웨이(SEG) 및 샌드박스 탐지를 우회했습니다. 링크를 통해 가짜 학술행사 안내 페이지로 유도한 뒤 ISO 디스크 이미지를 다운로드하도록 유도하고, 자동 마운트 특성을 악용해 내부에 숨긴 PIF(또는 유사 포맷) 실행을 유도합니다. 실행 시 정상 문서를 보여주며 백그라운드에서 암호화된 셸코드를 복호화해 프로세스 메모리에 악성 쉘코드를 주입하고, 파일리스 방식으로 변종 `RokRAT`을 메모리에 적재합니다. 이후 키로깅·화면 캡처·시스템 정보 수집 등을 수행하고, 텔레그램 API나 Dropbox/픽클라우드 등 상용 클라우드 API를 C2로 악용해 정보 유출을 시도했습니다. 공격자는 빌드타임 변조·안티포렌식 기법을 활용해 수사·조사 교란 정황도 발견되었습니다.

## 기술적 특징

- 사회공학(스피어피싱) 기반 표적 공격
- 상용 클라우드 링크를 악용한 SEG/샌드박스 우회
- ISO 자동 마운트·이중 확장자·PIF 포맷 악용
- 파일리스(메모리 인젝션) 기법으로 EDR/백신 우회
- 정상 HTTPS 트래픽 내 C2 통신(상용 클라우드 API 악용)
- 빌드타임 조작·안티포렌식 정황

## OWASP Top 10 관련 분석

아래는 이 캠페인과 연관성이 높은 OWASP Top 10(2021 기준)의 항목들과 그 이유입니다.

- **A04 — Insecure Design**: 공격자는 연구계의 정보 교류 설계(행사 자료·명단 공유)를 악용해 전통적 위협 모델을 우회했습니다. 설계 단계에서 인간 요소(사람 중심 플로우)를 충분히 고려하지 않으면 스피어피싱 경로가 그대로 남습니다.

- **A05 — Security Misconfiguration**: ISO 자동 마운트 허용, 미검증 외부 링크에 대한 허용 등 시스템·정책 설정이 공격에 이용되었습니다. SEG·샌드박스 정책이 상용 클라우드 링크를 통한 우회에 취약했습니다.

- **A08 — Software and Data Integrity Failures**: 공격자는 빌드타임 조작·안티포렌식 기법을 이용해 악성 코드를 은닉했고, 정상 서비스(클라우드 스토리지)를 C2로 악용해 데이터 무결성·신뢰성 검증 실패를 노렸습니다.

- **A09 — Security Logging and Monitoring Failures**: 파일리스·메모리 인젝션 기법과 정상 HTTPS 트래픽 내 C2 통신은 기존 파일 기반 탐지와 IP·시그니처 기반 모니터링에서 탐지하기 어렵습니다. 실시간 메모리 행위 및 비정상 클라우드 API 사용에 대한 로깅/모니터링이 부족하면 침해를 놓칠 가능성이 큽니다.

- **A02 — Cryptographic Failures (부분 관련)**: 공격자가 암호화된 셸코드를 사용하고 텔레그램/HTTPS를 통해 전송하는 점에서 전송·종단간 암호화 자체는 사용되지만, 신뢰성·무결성 검증(예: 서명 검증) 부족으로 악성 통신이 정상 트래픽으로 위장될 수 있습니다.

- **A07 — Identification and Authentication Failures (부분 관련)**: 표적형 이메일과 위조된 행사 페이지는 발신자/리소스의 신원 검증이 부족한 환경에서 효과적입니다. 강한 발신자 인증(DMARC/DKIM/SPF)·링크 무결성 검증이 취약하면 피싱 성공률이 높아집니다.

## 권고 조치

- 사용자 교육: 학술행사 초대·첨부파일·클라우드 링크에 대한 주의 강화
- 이메일 보안 강화: DMARC/DKIM/SPF 적용, URL 실시간 재작성·분석, 샌드박스 정책 개선
- 엔드포인트 가시성 확보: EDR로 메모리 행위(프로세스 인젝션·비정상 스레드 등) 모니터링
- 애플리케이션 제어: 허가되지 않은 ISO 마운트 및 PIF 실행 방지
- 네트워크 모니터링: 상용 클라우드 API 대상으로 비정상 트래픽 탐지·차단 룰 적용
- 무결성 검증: 빌드·배포 파이프라인 무결성 검사(서명, 빌드 타임스탬프 검증)
- 포렌식 준비: 안티포렌식 증거 대응 프로세스 수립 및 로그 보전
